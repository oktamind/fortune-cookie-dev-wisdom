One original fortune-cookie line for a software developer, in 64 characters: "The code you are afraid to touch has already touched everything." The truth every senior engineer knows — there is a module nobody dares change — turned on the word "touch": the fear is already too late, that code has its hands in everything.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
